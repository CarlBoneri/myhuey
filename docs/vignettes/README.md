# User-guided vignettes

These guides start with a task a person wants to finish, then work through the setup, the
decisions they need to make, and the result they should see. They use Markdown, shell commands,
and concrete outcomes.

| Guide | Start here when you want to… |
| --- | --- |
| [Install and run MyHuey](install-and-run.md) | Build the web app, install the Python package from a checkout, and open MyHuey locally |
| [Design a room layout](design-a-room-layout.md) | Create a safe sandbox, draw a room in Studio, and place its furniture and lights |

The install guide covers running from a source checkout. A wheel built from the current project
does not include the web app bundle, so it is not yet a standalone web-app deployment artifact.
